# FreqAI 示例

- `FreqaiExampleStrategy.py` + `user_data/config/config_freqai.json`
- 运行：`freqtrade trade --config user_data/config/config_freqai.json --strategy FreqaiExampleStrategy --freqaimodel LightGBMRegressor --userdir user_data --recursive-strategy-search`
- 依赖：`pip install "freqtrade[freqai]"` 或 lightgbm / datasieve / scikit-learn
- 文档：https://www.freqtrade.io/en/stable/freqai/

学习模板，不承诺收益。
