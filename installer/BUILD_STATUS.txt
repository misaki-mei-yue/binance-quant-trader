Windows setup.exe 构建说明
========================
正式安装包由 desktop/ 下 electron-builder 生成（NSIS）：
  BinanceQuantSetup-<version>.exe

- Linux 本机：一般无法直接打 Windows NSIS（需 wine）；请用 GitHub Actions windows-latest
- 旧版 Inno Setup 脚本 installer/installer.iss 已降级为备用
- UI：Electron + React + Tailwind（Apple 外壳 + 类交易终端工作区）
